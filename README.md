# Student Study & Exam Tracker 📘

## Description
The Student Study & Exam Tracker is a Python-based command-line application designed to help students manage their academic preparation. It allows users to track study hours for different subjects and store upcoming exam dates in an organized manner.

This project demonstrates practical problem-solving using Python and basic data persistence techniques.

## Features
- Add multiple subjects
- Log daily study hours
- Track total study time per subject
- Store exam dates
- Automatic data saving using JSON files

## Technologies Used
- Python 3
- JSON for data storage
- File handling
